통합 강의 관리자

과목별 공개/비공개 · 단원 제목 · 설명 · 교재 링크를 한 화면에서 관리합니다.

GitHub 연결

선택한 저장소의 Contents 읽기·쓰기 권한이 있는 fine-grained GitHub 토큰을 입력하세요. 토큰은 이 탭의 메모리에만 보관하며 과목을 변경하거나 토큰 지우기를 누르면 폐기합니다.

비공개는 강의 메뉴에서 숨기는 기능입니다. 게시된 학습 페이지의 직접 URL을 막는 접근 권한 설정은 아닙니다. 토큰을 공유 PC에서 사용하지 마세요.

과목을 선택하고 GitHub 인증을 진행하세요.

Chapter 정보 편집

단원 공개 전 학습 페이지가 저장소에 실제로 존재하는지 확인합니다. 변경은 'GitHub에 저장' 후 반영됩니다.

저장 후 GitHub Pages의 배포가 완료되면 학생용 화면에 반영됩니다. 이미 열린 화면은 새로고침이 필요합니다.
