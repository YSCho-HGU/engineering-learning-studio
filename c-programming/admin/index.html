단원 공개 및 정보 관리

공개/비공개 설정은 GitHub 저장소의 course-catalog.json을 갱신하며, 첫 화면의 단원 카드와 Course Overview에 함께 반영됩니다.

GitHub 인증

저장소 Contents 읽기·쓰기 권한이 있는 fine-grained Personal Access Token을 입력하세요. 토큰은 이 탭의 메모리에서만 사용하고 저장하지 않습니다.

주의: 관리자 화면은 누구나 주소로 열 수 있지만, GitHub 쓰기 권한 없이는 저장할 수 없습니다. 비공개는 메뉴에서 숨기는 것이며, 이미 게시된 학습 페이지 주소에 대한 접근을 차단하지는 않습니다.

공개 단원 목록을 불러오려면 인증해 주세요.

Chapter 공개 및 카드 정보 편집

공개 여부뿐 아니라 단원 제목·설명·교재 링크를 수정할 수 있습니다. 저장 전 공개할 학습 페이지의 존재 여부를 확인합니다.

저장 후 GitHub Pages에 배포되면 학생용 화면에 적용됩니다. 이미 열린 학생 페이지는 새로고침이 필요합니다.
