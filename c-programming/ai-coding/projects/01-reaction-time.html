Reaction Time Game

반응속도 측정 게임 — 신호가 초록색으로 바뀌는 순간 클릭해 나의 반응속도를 측정해 보세요.

V1 → V5 · Build Journey

Try it!

Start 후 초록색이 될 때 클릭하세요. 너무 일찍 클릭하면 다시 시도합니다.

버튼을 눌러 시작하세요.

My results

최근 최대 5회 결과를 표시합니다. 브라우저·기기 지연이 포함되는 학습용 측정입니다. 기록은 이 브라우저에만 저장될 수 있습니다.

Make it yours — 나만의 프로그램 만들기

먼저 위 완성 예제를 체험하세요. 그다음 Step 1을 원하는 AI 코딩 도구에 전달하고, 새 파일을 저장하여 실행합니다. 이후 필요한 기능만 하나씩 추가하세요. 위 예제는 실제 실행 프로그램이며 아래 Prompt는 외부 AI 도구에서 사용하는 학습 지시문입니다.

Step 1 · First success
반응속도를 측정하는 웹 게임을 만들어 줘. Start를 누르면 빨간색으로 바뀌고 1~3초의 임의 시간 후 초록색으로 바뀌게 해 줘. 초록색에서 클릭하면 반응시간을 ms로 표시해 줘. 별도 설치 없이 index.html 하나를 브라우저에서 실행할 수 있게 HTML, CSS, JavaScript를 모두 포함해 줘.
Step 2 · Improve
현재 게임의 측정 기능은 유지하고, 초록색 전에 클릭하면 False Start로 표시하고 재시도하게 해 줘. 타이머가 중복 실행되지 않도록 해 줘.
Step 3 · Analyze & visualize
최근 5회의 정상 기록을 배열에 저장하고 최솟값, 평균, 최근 값을 보여 줘. 막대그래프도 추가해 줘. 기록이 없을 때는 계산하지 말고 안내해 줘.
Step 4 · Persist & verify
localStorage에 최근 5회 기록을 저장하고 Reset 버튼을 추가해 줘. 조기 클릭은 기록하지 않으며, 새로고침 후 저장된 기록을 복구하는지 확인해 줘.
Step 5 · Learn with AI
상태 변수, 조건문, 배열, 함수가 각각 C에서 배운 어떤 개념에 해당하는지 설명해 줘. 내가 직접 바꿔 볼 수 있는 대기시간 범위 코드도 찾아 줘.

C에서 이미 배운 것

상태 변수(state), if/else, 배열, 함수, 평균 계산. Timer와 event는 새롭게 만나는 개념입니다.

다음 기술로 확장한다면

HTML/CSS/JavaScript → UI 상태가 많아지면 React + TypeScript. 여러 기기 기록이 필요할 때만 서버를 고려합니다.

직접 확인하기

  • 조기 클릭 시 기록이 증가하지 않는가?
  • 정상 클릭 시 ms 단위 결과가 표시되는가?
  • 6회 측정하면 최근 5개만 남는가?
  • Reset 후 기록이 0개인가?

AI에게 검증을 요청하기 전에 기대 결과를 직접 생각해 보세요.
