정렬 알고리즘 시각화 — C에서 배운 Bubble Sort를 막대그래프로 직접 추적해 보세요.

V1 → V5 · Build Journey

Input & control

C 알고리즘 보기
for (int i = 0; i < n - 1; i++) {
    for (int j = 0; j < n - 1 - i; j++) {
        if (a[j] > a[j + 1]) {
            int temp = a[j];
            a[j] = a[j + 1];
            a[j + 1] = temp;
        }
    }
}

유효한 정수 배열 a와 길이 n이 있다고 가정합니다. 웹 예제는 같은 로직을 JavaScript로 구현합니다.

먼저 위 완성 예제를 체험하세요. 그다음 Step 1을 원하는 AI 코딩 도구에 전달하고, 새 파일을 저장하여 실행합니다. 이후 필요한 기능만 하나씩 추가하세요. 위 예제는 실제 실행 프로그램이며 아래 Prompt는 외부 AI 도구에서 사용하는 학습 지시문입니다.

Step 1 · First success
C의 Bubble Sort 알고리즘을 웹에서 시각화해 줘. [5,2,4]를 막대그래프로 표시하고 Step 버튼을 누를 때마다 인접한 두 원소를 비교하여 필요할 때 교환하는 모습을 보여 줘. 단일 HTML 파일로 실행되게 해 줘.
Step 2 · Explore
배열을 직접 입력하게 하고 Random 버튼과 Reset을 추가해 줘. 현재 비교 중인 두 원소를 다른 색으로 표시해 줘.
Step 3 · Control
Previous, Play, Pause, 실행 속도 조절 기능을 추가해 줘. 비교 횟수와 교환 횟수도 보여 줘.
Step 4 · Verify
정렬된 배열, 역순 배열, 중복 값, 음수, 원소 하나를 테스트해 줘. C 코드의 루프 범위와 웹 시각화 결과가 일치하는지 검토해 줘.
Step 5 · Learn & extend
C의 중첩 for문과 swap 코드를 JavaScript 구현과 나란히 설명해 줘. 선택 정렬을 비교하는 선택 기능을 추가하려면 어떤 구조가 좋은지 제안해 줘.

C에서 이미 배운 것

배열, 인덱스, 중첩 반복문, if, swap, 알고리즘 추적.

다음 기술로 확장한다면

SVG/Canvas로 충분합니다. 여러 알고리즘을 비교하는 앱으로 발전시키려면 React 등 UI 프레임워크를 고려합니다.

직접 확인하기

  • [5,2,4]의 첫 두 Step이 [2,5,4], [2,4,5]인가?
  • [2,2,1]은 [1,2,2]로 정렬되는가?
  • [-3,0,-5]도 올바르게 정렬되는가?
  • Previous와 Reset이 정확한 상태를 복원하는가?

AI에게 검증을 요청하기 전에 기대 결과를 직접 생각해 보세요.
