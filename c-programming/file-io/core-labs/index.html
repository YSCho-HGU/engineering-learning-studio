파일에 한 줄 저장하기

상황: 프로그램이 실행되면 message.txt를 새로 만들거나 기존 내용을 지우고, 한 줄을 기록합니다. 코드를 읽은 뒤 어떤 내용이 파일에 남을지 먼저 예측하세요.

fopen("w")fprintf()fclose()
코드 작성 순서 · 3단계로 확인하기
  1. 파일 이름과 모드 "w"를 확인하고, 기존 파일이 있다면 내용이 어떻게 되는지 예측하세요.
  2. fopen()의 결과가 NULL인지 검사하고 fprintf()로 문장과 줄바꿈을 기록하세요.
  3. fclose()로 닫은 뒤 화면의 모의 파일 내용을 확인하고, 입력 문장을 바꿔 다시 실행하세요.
전체 C11 프로그램입력 문장을 바꾸면 fprintf()의 문자열도 바뀝니다.
파일을 열고(NULL 검사), 한 줄을 기록한 뒤 닫습니다. "w" 모드는 기존 파일 내용을 덮어씁니다.

CORE 02
파일에서 한 줄 읽고 출력하기
상황: message.txt에는 여러 줄이 들어 있습니다. fgets()를 단 한 번 호출하면 첫 줄만 읽습니다. 화면에 출력되는 내용을 먼저 예측하세요.


fopen("r")fgets()fputs()fclose()

코드 작성 순서 · 3단계로 확인하기

  1. "r" 모드로 파일을 열고 fopen() 실패 여부를 먼저 확인하세요.
  2. char line[80] 버퍼에 fgets()를 한 번만 호출하고, 성공한 경우에만 fputs()를 사용하세요.
  3. 첫 줄과 둘째 줄을 다르게 입력하고, 한 번의 fgets() 호출로 어느 부분이 출력되는지 확인하세요.






전체 C11 프로그램첫 번째 줄만 읽는 기본 프로그램
#include <stdio.h>
int main(void) {
    FILE *fp = fopen("message.txt", "r");
    char line[80];
    if (fp == NULL) return 1;

    if (fgets(line, sizeof line, fp) != NULL)
        fputs(line, stdout);

    fclose(fp);
    return 0;
}
fgets()는 버퍼 크기를 전달받아 한 번에 문자열 일부 또는 한 줄을 읽습니다. 성공했을 때만 fputs()로 출력합니다.


예측: 두 번째 줄도 출력될까요? 빈 파일이라면 어떨까요?

CORE 03
학생 레코드를 구조체에 읽고 학점 계산하기
상황: students.txt의 한 레코드에는 학번, 이름, 점수가 기록되어 있습니다. 세 값을 struct Student에 넣고, 점수를 A~F 학점으로 환산해 출력합니다. 먼저 한 명을 정확히 처리하는 법을 익힙니다.


fopen("r")fscanf()struct Studentgrade()fclose()

코드 작성 순서 · 3단계로 확인하기

  1. Student 구조체의 id, name, score 멤버와 입력 파일의 세 필드를 대응시키세요.
  2. fscanf()의 반환값이 3인지 확인하고, 이름에는 %39s로 버퍼 길이를 제한하세요.
  3. 점수를 grade()에 전달해 A–F를 얻고, 학번·이름·점수·학점의 출력값을 비교하세요.






전체 C11 프로그램학생 한 명을 처리하는 기본 형태
#include <stdio.h>
struct Student {
    int id;
    char name[40];
    double score;
};
char grade(double score) {
    if (score >= 90) return 'A';
    if (score >= 80) return 'B';
    if (score >= 70) return 'C';
    if (score >= 60) return 'D';
    return 'F';
}
int main(void) {
    struct Student s;
    FILE *fp = fopen("students.txt", "r");
    if (fp == NULL) return 1;

    if (fscanf(fp, "%d %39s %lf",
               &s.id, s.name, &s.score) != 3) {
        fclose(fp);
        return 1;
    }
    fclose(fp);
    if (s.score < 0 || s.score > 100) return 1;
    printf("%d %s %.1f %c\n",
           s.id, s.name, s.score, grade(s.score));
    return 0;
}
fscanf()가 3을 반환하면 학번·이름·점수를 모두 성공적으로 읽은 것입니다. 정수·실수에는 &, 문자 배열 이름에는 & 없이 전달합니다.


예측: s.id, s.name, s.score와 A~F 학점은 각각 무엇일까요?
실행 전에 결과를 예측해 보세요.
성적 기준: A ≥ 90, B ≥ 80, C ≥ 70, D ≥ 60, F < 60 (실습용 기준)
