4 · EXPLAIN & TRANSFER
fscanf(...) == 1이 왜 적절할까요? 반환값 0과 EOF가 서로 다른 이유는 무엇일까요? 정상 파일과 ABC가 포함된 파일을 비교해 보세요.
핵심 원리 힌트
fscanf는 성공한 변환·대입 개수를 반환합니다. 정수 하나를 읽으면 1, 형식이 맞지 않으면 0, 입력 전에 파일 끝에 도달하거나 읽기 오류가 발생하면 EOF가 가능합니다. 종료 후 feof(fp)와 ferror(fp)를 구분합니다.
