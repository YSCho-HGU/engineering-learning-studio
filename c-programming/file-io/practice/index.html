확인할 핵심 · fgets는 최대 79바이트를 읽고 '\\0'를 붙이며, 읽은 개행 '\\n'은 유지될 수 있습니다. fputs는 종료 문자 '\\0'를 출력하지 않고, 개행도 자동으로 추가하지 않습니다. 실제 출력은 버퍼링될 수 있어 fclose 결과도 확인해야 합니다.


GCC 실행 방법 · 다운로드한 코드 검증
① 코드를 p1_file_io.c처럼 다운로드합니다. ② 필요한 입력 파일을 같은 작업 폴더에 준비합니다. ③ 터미널에서 gcc -std=c11 -Wall -Wextra -Wpedantic -Werror p1_file_io.c -o p1로 컴파일합니다. ④ ./p1 (Windows에서는 p1.exe)을 실행합니다. P1은 표준 입력으로 다섯 정수를 입력합니다. P2~P6는 화면의 테스트 데이터로 해당 파일을 먼저 만듭니다. M1은 제공된 message.txt를 다운로드하여 같은 폴더에 두고 실행한 뒤 preview.txt의 첫 줄만 비교합니다. ⑤ 실제 출력 파일을 열어 참조 결과와 비교합니다.
코드를 작성한 다음 핵심 구문을 점검하세요. 점검 결과는 컴파일 성공을 의미하지 않습니다.
이 기록은 자기보고이며 자동 컴파일 인증이 아닙니다. 코드를 수정하면 다시 확인해야 합니다.
