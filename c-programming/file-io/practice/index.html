실행 환경 안내: 이 페이지는 GitHub Pages에서 동작하는 오프라인형 학습 시뮬레이터입니다. C 소스를 실제 GCC로 컴파일하거나 실행하지 않습니다. 「코드 점검」은 정규식 기반의 핵심 구문 점검이고, 「예상 결과」는 교재 요구사항에 맞는 참조 동작입니다. 문법·컴파일·실행의 최종 검증은 다운로드한 .c 파일을 GCC에서 수행해야 합니다.

GCC 실행 방법 · 다운로드한 코드 검증
① 코드를 p1_file_io.c처럼 다운로드합니다. ② 필요한 입력 파일을 같은 작업 폴더에 준비합니다. ③ 터미널에서 gcc -std=c11 -Wall -Wextra -Wpedantic -Werror p1_file_io.c -o p1로 컴파일합니다. ④ ./p1 (Windows에서는 p1.exe)을 실행합니다. P1은 표준 입력으로 다섯 정수를 입력합니다. P2~P6는 화면의 테스트 데이터로 해당 파일을 먼저 만듭니다. ⑤ 실제 출력 파일을 열어 참조 결과와 비교합니다.
코드를 작성한 다음 핵심 구문을 점검하세요. 점검 결과는 컴파일 성공을 의미하지 않습니다.
이 기록은 자기보고이며 자동 컴파일 인증이 아닙니다. 코드를 수정하면 다시 확인해야 합니다.
