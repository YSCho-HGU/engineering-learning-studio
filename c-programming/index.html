Pointer Lab · 값과 주소를 구분하기

가상 주소 0x1000은 설명을 위한 예시입니다. 실제 주소는 실행 환경에 따라 달라집니다.

0x1000 · x

10

0x2000 · p

&x

int x = 10; int *p = &x;

p stores the address of x; *p reads x.

int x = 10;
int *p = &x;
*p = 40;  // changes x, not a separate copy

Predict: After *p = 40, what is x?

Key idea: C passes pointer arguments by value; dereferencing can still change the caller's object.

File I/O Lab · 파일은 프로그램 종료 후에도 남습니다

브라우저 메모리에서 파일 작업을 모의 실행합니다. 실제 PC 파일을 생성하거나 C 코드를 실행하지 않습니다.

Suggested exercise: Reset Lab → open r → fgets twice → fclose → open a → fprintf → fclose → Restart program. The saved file stays changed. Mode w intentionally erases existing contents.

FILE *fp = fopen("sensor.txt", "r");
if (fp == NULL) { /* handle error */ }
else {
    char line[80];
    while (fgets(line, sizeof line, fp) != NULL) {
        fputs(line, stdout);
    }
    fclose(fp);
}

Predict: If sensor.txt exists, what does successful fopen("sensor.txt","w") do?

Read functions report success/failure; avoid while (!feof(fp)) as the read-loop condition.
