One Learning Method · 공통 학습 철학

  1. Understand: 왜 필요한지 핵심 개념을 이해합니다.
  2. Predict: C 코드의 실행 결과를 먼저 예상합니다.
  3. Explore: 메모리 상태나 파일 내용을 조작하며 비교합니다.
  4. Practice: P1~P6 코드를 직접 작성합니다.
  5. Check: 개념 퀴즈와 GCC 실행을 서로 다른 학습 증거로 관리합니다.

Activity는 학습 활동 기록, Concept는 객관식 핵심 문제 정답 기록, Coding은 학생이 별도로 수행한 GCC 확인입니다. 브라우저는 실제 C 소스를 컴파일하지 않습니다. 모든 진도는 이 브라우저에만 저장됩니다.
