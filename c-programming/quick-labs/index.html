Pointer Lab · 값과 주소를 구분하기

가상 주소 0x1000은 설명을 위한 예시입니다. 실제 주소는 실행 환경에 따라 달라집니다.

0x1000 · x

10

0x2000 · p

&x

int x = 10; int *p = &x;

p stores the address of x; *p reads x.

int x = 10;
int *p = &x;
*p = 40;  // changes x, not a separate copy

Predict: After *p = 40, what is x?

Key idea: C passes pointer arguments by value; dereferencing can still change the caller's object.
